# 🚀 DataPulse
پلتفرم هوشمند تحلیل رفتار مشتری برای فروشگاه‌های آنلاین

---

## 📋 مشخصات پروژه

| عنوان | توضیح |
| :--- | :--- |
| نام پروژه | DataPulse |
| نوع پروژه | پایگاه داده تحلیلی + هوش مصنوعی |
| تیم | ۱۰ نفره (همه اعضا نقش مشخصی دارند) |
| معماری داده | ترکیبی از Data Mesh و Data Lakehouse |
| ابزارهای اصلی | PostgreSQL, Docker, Python, Git, DBeaver |

## 🎯 هدف پروژه (یک خطی)

DataPulse داده‌های خرید، کلیک، سبد خرید و بازخورد مشتریان فروشگاه‌های آنلاین را جمع‌آوری، پردازش و تحلیل می‌کند تا با استفاده از هوش مصنوعی، رفتار آینده مشتریان را پیش‌بینی کرده و به فروشگاه‌ها داشبورد لحظه‌ای و سیستم توصیه‌گر محصول ارائه دهد.

## 🛠️ ابزارهای مورد استفاده

| دسته | ابزارها |
| :--- | :--- |
| دیتابیس اصلی | PostgreSQL 17 (اجرا شده با Docker) |
| مدیریت دیتابیس | DBeaver (یا هر کلاینت SQL دیگر) |
| کنترل نسخه | Git + GitHub |
| زبان برنامه‌نویسی | Python 3.11+ |
| کتابخانه‌های Python | psycopg2-binary, pandas, sqlalchemy, fastapi, uvicorn |
| سیستم‌عامل | macOS (همراه با Docker Desktop) |
